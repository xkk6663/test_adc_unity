## 文档维护规范

1. **每次代码变更同步更新对应文档**
2. **新增模块时**：更新 03-架构设计（目录结构）、04-详细设计（接口）、05-测试方案、06-测试用例
3. **CI/CD 变更时**：更新 09-运维文档，并在根目录 `CI-CD排错日志.md` 记录故障
4. **版本发布时**：更新 08-发布说明，添加版本记录
5. **文档编号固定**：不随意调整序号，新增文档追加编号
