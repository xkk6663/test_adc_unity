## v1.0.0（2026-09-05）

### 新增

- **产品级代码架构分层**（仿照 ELAB 框架）
  - `app/` 应用层：battery/、led/ 业务模块
  - `hal/` 硬件抽象层：hal_adc.h、hal_gpio.h 接口
  - `platform/` 平台层：firmware/ 固件主程序
  - `test/` 测试层：unit/ 单元测试、mocks/ CMock 桩
  - `framework/` 第三方框架：unity/、cmock/
  - `tools/` 工具脚本：gen_mocks.rb、CMockConfig.yml

- **产品级 CI/CD 流水线**（三 Job）
  - Job 1：静态分析（cppcheck，检查 app/hal/platform）
  - Job 2：多平台构建矩阵（Ubuntu/gcc + macOS/clang + Windows/MSVC-Ninja）
  - Job 3：测试覆盖率（gcov + lcov，HTML 报告上传）

- **完整产品开发文档链**（doc/ 目录，9 份文档）
  - 01-MRD-市场需求文档
  - 02-PRD-产品需求文档
  - 03-技术架构设计
  - 04-详细设计文档
  - 05-测试方案
  - 06-测试用例
  - 07-用户手册
  - 08-发布说明（本文档）
  - 09-运维与CICD文档

- **CI/CD 排错日志**（CI-CD排错日志.md）
  - 记录 7 次 CI 失败的根因分析和修复方案

### 变更

- 目录结构从扁平重构为六层分层
- Makefile 重写为分层 INCLUDES + 分层源文件路径
- CMakeLists.txt 重写为产品级分层
- gen_mocks.rb 适配新路径（输入 hal/，输出 test/mocks/）
- CMockConfig.yml 输出路径改为 test/mocks/
- README 完全重写为产品级架构文档
- .gitignore 添加覆盖率相关规则

### 修复

- CI Windows 平台 shell 兼容性（PowerShell 不支持 Unix 语法 → 指定 shell: bash）
- CI Windows 平台 CMake 生成器（Visual Studio 不可用 → 改用 Ninja+MSVC）

### 已知问题

- 无

### 兼容性

- 构建系统：Makefile + CMake（双构建）
- 编译器：gcc / clang / MSVC
- 操作系统：Windows / Linux / macOS
- C 标准：C99

### 升级指南

从 v0.3.0 升级到 v1.0.0：

```bash
git pull origin main
# 目录结构已变更，旧的扁平文件已移动到新目录
# 构建命令不变：make all / cmake -S . -B build
```
